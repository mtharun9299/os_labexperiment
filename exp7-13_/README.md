# Operating Systems Lab Programs

VS Code-ready C programs based on Experiments 7–13.

## Requirements
- Visual Studio Code
- GCC compiler
- VS Code C/C++ extension (recommended)

## Compile
Open the integrated terminal in VS Code and run:

```bash
gcc filename.c -o program
./program
```

For the Pthreads program:

```bash
gcc threading.c -o threading -pthread
./threading
```

## Programs
- Experiment 07: Banker's Algorithm
- Experiment 08: Deadlock Detection Algorithm
- Experiment 09: POSIX Pthreads
- Experiment 10: Paging Technique
- Experiment 11: First Fit, Best Fit, Worst Fit
- Experiment 12: FIFO, LRU, Optimal Page Replacement
- Experiment 13: Sequential, Direct, Indexed File Organization

The programs follow the uploaded lab PDFs' terminology and examples.
